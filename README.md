## Три прохода доработки

1. Десктоп: проверена композиция, убрано наложение подписи на морду кота, подпись вынесена в лаймовую плашку, увеличена мелкая типографика, уточнена высота hero.
2. Мобильная версия 390 px: отдельная композиция портрета, уменьшено тонирование шерсти градиентом, исправлена доступная подпись меню, увеличены зоны касания и основной текст.
3. 320 px и интерактивность: окно записи помещается, Escape закрывает его, услуги переключаются, изображения загружаются, горизонтального переполнения нет. Проверена внешняя страница записи. Добавлено деликатное движение плашек за курсором и доступное название диалога. Поддержан prefers-reduced-motion.
